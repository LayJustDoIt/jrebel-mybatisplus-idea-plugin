# MyBatis-Plus Reload v1.0.1 — Release Notes

## English

**Version 1.0.1**

- Added compatibility with IntelliJ IDEA 2026.3.
- Maintained compatibility with IntelliJ IDEA 2026.2.
- Preserved automatic JRebel runtime injection.
- Continued support for Mapper XML hot reload.
- Bundled the unchanged jrebel-mybatisplus runtime 1.0.8.

### Compatibility

- IntelliJ IDEA 2026.2 (since-build 262)
- IntelliJ IDEA 2026.3 (until-build 263.*)
- Runtime: jrebel-mybatisplus 1.0.8

### Verification

- Plugin Verifier (IU-262.8665.337): Compatible — 0 internal / deprecated / experimental / forbidden API usages.
- Plugin Verifier (IU-263.7307.200): Compatible — 0 internal / deprecated / experimental / forbidden API usages.
- 6 unit tests (rebel.plugins merge logic) passed.
- Real-project E2E on IDEA 2026.3: plugin installs and loads; JRebel Debug launches normally;
  Mapper XML SQL hot reload works; MyBatis-Plus injected SQL (`selectPage`) stays intact;
  no JVM restart required; no repeated XML reloads on normal requests.
